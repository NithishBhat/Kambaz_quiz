# Kambaz Quiz

The starting point for a quiz feature in **Kambaz**, a Canvas-style course management app. It is set up as a Node.js project for a quiz server.

> **Status:** initial scaffold. It has `package.json` and a placeholder `hello.js` script so far.

## Running

```bash
node hello.js
```
